# JavaScript-Projekt

## Beschreibung

Dieses Projekt ist eine kleine interaktive JavaScript-Webseite, die verschiedene grundlegende Funktionen von JavaScript demonstriert.

Das Projekt wurde mit **HTML, CSS und JavaScript** umgesetzt und zeigt, wie JavaScript verwendet werden kann, um Webseiten dynamisch und interaktiv zu gestalten.

## Funktionen

### ⏳ Countdown

Die Webseite enthält einen Countdown bis zum Frühlingsanfang. Die verbleibende Zeit wird automatisch jede Sekunde aktualisiert.

### 🎨 Zufällige Hintergrundfarbe

Beim Laden der Webseite wird automatisch eine zufällige Hintergrundfarbe ausgewählt.

### 📝 Dynamische Texte

Über ein Eingabefeld kann ein eigener Text eingegeben werden. Zusätzlich kann eine Farbe ausgewählt werden. Mit einem Klick auf den Button wird der Text als neuer Absatz auf der Webseite angezeigt.

### 🖼️ Bildergalerie

Das Projekt enthält eine kleine Bildergalerie. Durch Anklicken eines Vorschaubildes wird das entsprechende Bild als großes Bild angezeigt.

## Verwendete Technologien

- HTML5
- CSS3
- JavaScript
- DOM-Manipulation
- JavaScript Events
- `setInterval()`
- `Math.random()`
